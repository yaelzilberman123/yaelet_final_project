החלק הראשון מיועד להשוואה בין כמה אורגניזמים ובדיקה של חיזוי מקור הגן, את הקבצים הנלווים אליו יש לשים בתיקייה בתוך data ששמה gene, התוצאות יופיעו בתיקייה בresults  בvisualizations בfinal results ובresult comparison.
החלק השני עוסק ההחינת הקשר בין מרחק אבולוציוני לדיוק החיזוי לפי הטיית הקודונים, שאליו צריכים גם לשים קבצי CDS בלבד+ מרחק גנטי מחושב מראש לפי 16S rRNA (https://www.ebi.ac.uk/jdispatcher/psa/emboss_needle ) את ההשוואה ניתן לעשות דרך הכלי הזה כשנכסים לתוצאות תחת הכותרת identity.
את קבצי ה CDS מכניסים לתיקיית semi_results (חשוב שהאורגניזם הראשון בתיקייה יהיה האורגניזם שאליו משווים את מרחק כדי שהתוכנית תעבוד כראוי )
בתקיית הscripts בתוך main יש למטה בקוד משתנה בעל השם evo_distances, לכל קובץ שימו את שמו המלא במרכאות כמו בדוגמה הזו: "organism_name_cds.fna" ואת אחוז ההתאמה שקיבלתם מהכלי,
בסוף ההרצה תוכלו לראות את התוצאות תחת evodist_results.
